Jawaban LKPD Matematika SPLDV

Berdasarkan Iklan RedisC dari Barang Bekas

1. Menentukan Variabel

Misalkan:
x = Harga 1 kerajinan bunga
y = Harga 1 jam dinding

2. Membuat Model Matematika

Paket 1:

5x + 2y = 275.000

Paket 2:

3x + 2y = 185.000

3. Menentukan Harga Masing-Masing Produk

Metode Eliminasi:

5x + 2y = 275.000 | × 1
3x + 2y = 185.000 | × 1

5x + 2y = 275.000
3x + 2y = 185.000
------------------------ -
2x = 90.000
x = 90.000 / 2
x = 45.000

Metode subtitusi:

5x + 2y = 275.000
5(45.000) + 2y = 275.000
225.000 + 2y = 275.000
2y = 275.000 - 225.000
2y = 50.000
y = 50.000 / 2
y = 25.000

Jadi, hasilnya adalah:

  • Harga 1 kerajinan bunga = Rp45.000
  • Harga 1 jam dinding = Rp25.000

4. Kesimpulan

Berdasarkan perhitungan menggunakan metode eliminasi dan substitusi, diperoleh harga satu kerajinan bunga sebesar Rp45.000 dan harga satu jam dinding sebesar Rp25.000. Dengan demikian, SPLDV dapat digunakan untuk menentukan harga masing-masing produk berdasarkan dua paket penjualan.
