Penyelesaian Soal SPLDV

Berdasarkan Iklan CycleSmart

1. Menentukan Variabel

Misalkan:
x = Harga 1 jam dinding hias dari CD bekas
y = Harga 1 lampu hias kerajinan

2. Membuat Model Matematika

Paket 1:

3 jam dinding dan 5 lampu hias seharga Rp290.000.

Paket 2:

4 jam dinding dan 3 lampu hias seharga Rp240.000.

3. Membuat Persamaan

3x + 5y = 290.000 ... (1)
4x + 3y = 240.000 ... (2)

4. Penyelesaian Metode Campuran

A. Metode Eliminasi

Persamaan (1) dikalikan 3:
3x + 5y = 290.000 | × 3
9x + 15y = 870.000

Persamaan (2) dikalikan 5:
4x + 3y = 240.000 | × 5
20x + 15y = 1.200.000

9x + 15y = 870.000
20x + 15y = 1.200.000
-------------------------
-11x = -330.000
x = 330.000 : 11
x = 30.000

B. Metode Substitusi

Masukkan x = 30.000 ke persamaan (1).

3x + 5y = 290.000
3(30.000) + 5y = 290.000
90.000 + 5y = 290.000
5y = 290.000 - 90.000
5y = 200.000
y = 200.000 : 5
y = 40.000

5. Hasil Akhir

Jadi, hasilnya adalah:

  • Harga 1 jam dinding hias dari CD bekas = Rp30.000
  • Harga 1 lampu hias kerajinan = Rp40.000

6. Kesimpulan

Berdasarkan penyelesaian menggunakan metode campuran, yaitu metode eliminasi dan substitusi, diperoleh bahwa harga 1 jam dinding hias dari CD bekas adalah Rp30.000, sedangkan harga 1 lampu hias kerajinan adalah Rp40.000.
